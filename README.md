# Demo model bundle

Trimmed model bundle used by the hosted demo of github.com/ram15x/personalized-recommendation-engine (branch `main`, see `docs/deploy_space.md`).

Contents: two-tower weights, item vectors, item-KNN neighbours, DCN-v2 and Wide & Deep weights, film titles and genres, aggregate statistics.
It contains no per-user rating histories. MovieLens 25M itself is not redistributed here; get it from https://grouplens.org/datasets/movielens/25m/.
